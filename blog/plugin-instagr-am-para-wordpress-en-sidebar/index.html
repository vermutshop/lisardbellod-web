Plugin Instagr.am para WordPress en sidebar

Lisard Bellod · 6 de marzo de 2011

Todos los que tenemos la suerte de tener un iPhone, seguro que habremos probado alguna vez este sencillo programa para echar, editar y publicar una foto en la nube. Instagr.am

Pues desde que lo tuve en mi iPhone siempre le daba vueltas a como poder añadir estas fantásticas fotos en mi blog o web automáticamente.

Y tachan!!! Apareció el plugin, al cual pensé, pues que caca que me cargue 20 fotos en la barra lateral de mi blog, me faltaran páginas. Ya que en la definición del plugin pone eso, que te muestra las ultimas 20 fotos que has subido a la web de instagram.  Pero resulta que las carga como diapositivas. Además un efecto muy sencillo y bonito. El cual da un efecto al blog impresiónate. Por lo menos a mi me gusta.

Lo mejor de todo es que si tienes instalado el plugin de Fancy cuando le das a una imagen se carga en la principal a tamaño real.

..

Instalación:

  • Se intala como todos los plugins,
  • Conseguimos la ID de la Api aquí: Instagram Api
  • Y según las instrucciones solo tenemos que añadir una url de cualquier foto nuestra.
  • Asignar el tamaño en el widget y palante!!
