Desaparecerá Windows Vista ?

Lisard Bellod · 12 de diciembre de 2007

A los que estéis en el mundillo informático no creo que tengáis muchos problemas por recordar el fantástico Windows Millenium ( jeje digámosle Windows del año 1000, jeje ) el cual fue un desastre con mayúsculas. Y que le paso? Pues que duro 4 días ( metafóricamente ) ya que las ventas eran casi nulas y los problemas a montones…

Pues como esta Windows Vista actualmente? Muy mal. Las ventas son un desastre pero, solo un pequeño dato. De cada 10 Windows XP se vende un 0.8 de Vista. Windows quizás diga que se venden a millones, pero a pie de calle no es así, la gente no lo quiere.

  • Problemas: en todo no se salva ni el Msn.

Por lo que he ido viendo y me han contado es que están desarrollando la nueva actualización ( win nuevo ) desde la base, en pocas palabras. Están haciendo un S.O nuevo. Igual que con el millenium…

En enero mas o menos se sabrá algo, pero de mientras, buscar el XP que no falla ( tanto ) como el Vista…
