Ahtec Netbook N011, el primer portátil Atom de España?

Lisard Bellod · 5 de junio de 2008

Si os digo que dentro de nada tenemos entre nosotros el nuevo Intel Atom os sonara a chino, pero lo siguiente espero lo entendáis mejor.

  • Portátil 1,2kg
  • 80gb de disco duro ( ampliable hasta 320gb!! )
  • 10”2 pulgadas panorámico
  • Compatible con el Win Xp
  • Intel Atom 1,6ghz ( consumo muy bajo )
  • 1gb de Ram configurable ( se podrá ampliar ram hasta 2gb )

Precio: Desde 399€ Iva Incluido!!

Realmente por las características que tiene es apto para todo tipo de funciones que podéis utilizar actualmente en el ordenador que tengáis. A si que dentro en menos de un mes nadie tendrá la excusa de no tener un portátil, funciones que le podemos sacar rápidamente:

  • Compañero de viaje para descargar y ver las fotos de la cámara. ( Lector de tarjetas integrado )
  • Tu agenda personal, email, web, videoconferencia, voiP
  • No pesa!!!! Te lo puedes llevar a todos lados. Es como llevar un saco de arroz encima.

Realmente es de las herramientas que hay que tener tanto seas usuario avanzado como si no lo eres.

Si no pasa nada dentro de muy poco podré testear uno y si me dejan hacer alguna que otra foto. Y como siempre mi eterna duda.
