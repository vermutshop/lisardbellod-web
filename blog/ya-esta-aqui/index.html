Ya esta aquí!

Lisard Bellod · 2 de diciembre de 2006

Ya ha llegado a casa,
después de 20 días, de nervios, se acerca la navidad y el curro a tope, pero el botón de recargar la web hasta se ha borrado un poco 🙂 jeje, pues ya lo tengo en casa, Mi primer portátil.
Que decir: pues que después de muchas dudas, con los core Duo. El core 2 duo me ha sorprendido, pero muchísimo, utilizando aplicaciones Roseta, por ejemplo el Office, pues vuela, con photoshop ni se lo piensa, lo hace,
Personalmente un relámpago de ordenador, funciona genial, ahora ando liado con el tema  del Boot Camp, haber si consigo instalar el windows ( aunque solo para el battlefield 2 ) ya viendo como funciona con el Core 2 Duo ni de coña utilizar el Windows,
Otra cosa a destacar, el wiffi, lo coge todo, no pierde señal, y menos cuando se esta lejos del rooter, cosa que otros si que les pasan cosas de estas, será el mac?? jeje, el tiempo lo dirá,
Bueno ahora a currar el doble, pero desde el sofá,
