Como se hace un mojito?

Lisard Bellod · 18 de julio de 2007

Pues es de esas bebidas ( alcohólicas, si eres menor ya tendrás tiempo para probarlo ) que en veranito cuando empieza a refrescar y estas en el balcón de tu casa o en un jardín pues apetece. Y como se prepara:

  • Ron: como mas viejo y bueno mejor
  • Limón: natural ( si no tenéis se puede utilizar Pulco )
  • Hielo.
  • Menta fresca. ( indispensable )
  • Azúcar.

Cogemos un baso bien resistente y trituramos 3 o 4 cubitos, juntamente con la menta.
( no trituraremos la menta con el Ron ya que desprendería demasiado aroma )
Cuando esta todo bien triturado, como si fuera un granizado, tiraremos el ron. Más o menos para cubrir el hielo.
Exprimiremos el limón. Si el limón es mediano-pequeño. Tiraremos todo el jugo al cocktail.
Finalmente tiraremos el azúcar hasta reducir el exceso de acidez del limón.

Y Tachan! Un buen mojito a la cubana.

PD: La foto de del mojito no es un buen ejemplo ya que el hielo y la menta no esta triturado pero quedaba muy bien.
